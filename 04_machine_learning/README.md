# Machine Learning

Notebooks and data are organized by modeling task:

- `fundamentals/` — introductory model-building lessons.
- `regression/` — regression notebooks and supporting datasets.
- `classification/` — classification, ROC, and AdaBoost exercises.
- `clustering/` — DBSCAN and other unsupervised-learning work.
- `recommender_systems/` — movie recommendation notebooks.
- `projects/` — end-to-end supervised-learning project work.
- `datasets/` — shared datasets for these machine-learning lessons.
