# Computer Vision

Computer-vision learning materials remain separate from the general analysis
and machine-learning areas.

- `notebooks/` — introductory computer- and machine-vision notebooks.
- `image_processing/` — later image-processing lesson notebooks.
- `work_in_progress/` — unfinished machine-vision notebooks retained for
  continued study.
- `assets/` — image, video, and font inputs grouped by their original source
  collection to avoid filename collisions.
