# Programming Learning Portfolio

This repository is organized as a progressive learning path. Start with Python
programming, then apply those foundations to algorithms, data analysis,
machine learning, and computer vision.

```text
01_python/             Python fundamentals and practice
          ↓
02_algorithms/         Algorithmic problem solving
          ↓
03_data_analysis/      NumPy, pandas, visualization, and datasets
          ↓
04_machine_learning/   Supervised and unsupervised learning
          ↓
05_computer_vision/    Image-processing and vision notebooks
```

Each numbered directory is intentionally self-contained. Supporting datasets,
notebooks, and image assets live beside the work that uses them instead of in a
shared top-level folder.

## Areas at a glance

| Area | Focus |
| --- | --- |
| `01_python/` | Core language concepts, functions, files, OOP, and small projects. |
| `02_algorithms/` | Number-theory and sequence exercises built with Python. |
| `03_data_analysis/` | Array computing, tabular analysis, visualization, and source data. |
| `04_machine_learning/` | Regression, classification, clustering, recommenders, and projects. |
| `05_computer_vision/` | Image processing lessons, vision notebooks, and their image assets. |
