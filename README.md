## 📁 File Organization

Each numbered directory is self-contained:

```
01_python/
├── fundamentals/           # Core syntax (110+ files)
├── control_flow/           # Loops and conditionals (38 files)
├── data_structures/        # Lists, dicts, sets (30 files)
├── functions/              # Function practice (37 files)
├── oop/                    # Classes and objects (4 files)
├── files_and_databases/    # File I/O and SQLite (30 files)
├── projects/               # Application projects (4 files)
└── README.md               # Section guidance
```

Supporting data, notebooks, and assets live with their related code rather than in a shared top-level folder—easier to navigate and reuse.

## 📝 File Naming Convention

Files follow descriptive naming patterns for clarity:

- **Python files:** `{concept}_{detail}.py`
  - Example: `binary_search.py`, `list_operations.py`
- **Notebooks:** `{topic}_{description}_{dataset}.ipynb`
  - Example: `clustering_kmeans_iris.ipynb`, `regression_house_price.ipynb`

This makes it immediately clear what each file contains.
