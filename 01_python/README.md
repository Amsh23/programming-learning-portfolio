# Python

Core Python learning materials are grouped by the primary concept practiced:

- `fundamentals/` — syntax, values, strings, and introductory exercises.
- `control_flow/` — conditionals, loops, and pattern exercises.
- `data_structures/` — lists, tuples, dictionaries, and sets.
- `functions/` — reusable functions and function-focused exercises.
- `files_and_databases/` — file handling and SQLite practice.
- `oop/` — classes and object-oriented examples.
- `projects/` — small GUI and application exercises.

Algorithm-focused Python exercises continue in [`../02_algorithms/`](../02_algorithms/README.md).
